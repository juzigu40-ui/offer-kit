# 漏洞报告合规急救

价格：300 元人民币 / 50 美金起。  
交付：24 小时内整理 1 份漏洞报告草稿，或 3 段安全相关公开文案。

## 适合谁

- 已经有授权范围内的漏洞报告草稿，但表达太乱的人。
- 做开源安全修复，需要把影响、验证和边界写清楚的人。
- 需要给维护者或漏洞平台提交简短、克制、可复查报告的人。

## 交付内容

- 标题重写：不夸大影响，写清漏洞类型和受影响位置。
- 报告结构：Scope、Affected area、Steps、Impact、Evidence、Mitigation、Boundaries。
- 风险降噪：删掉吓人的大词，把影响写成条件句。
- 边界补全：补“未测试生产系统、未访问数据、未使用 secret”等声明。
- 可选短版：给维护者私下披露或 PR 描述用。

## 边界

- 不做未授权测试。
- 不登录任何漏洞平台或第三方系统。
- 不生成破坏性利用步骤。
- 不处理真实 secret、token、客户数据或生产系统截图。
- 不保证平台接受、漏洞评级或 bounty payout。

## 需要客户给的材料

- 授权范围或平台规则链接。
- 报告草稿或已知问题描述。
- 低风险复现步骤或本地测试结果。
- 受影响文件、接口、版本或页面。
- 已做和未做的验证。

不做未授权测试，不写破坏性利用步骤，不碰真实 secret 或生产系统。

# Release / CI 小修

价格：300 元人民币 / 50 美金起。  
交付：24 小时内处理 1 个明确的 release、CI、打包或 README 发布流程小问题。

## 适合谁

- 开源项目维护者。
- 小产品作者。
- 正在投 PR / bounty、需要把改动讲清楚的人。
- release、打包、CI 或 README 发布步骤里有一个小卡点的人。

## 可以做

- 修 dry-run、版本替换、zip 路径、上传前检查、跨平台 shell 差异。
- 补 `.env.example`、修 lint / test 命令、让失败原因更容易定位。
- 核对 distignore、manifest、zip 内容是否漏文件或误带开发文件。
- 把 README / release 文档改到和脚本一致。
- 给 PR 写清楚问题、改动、验证和剩余边界。

## 边界

- 不使用你的 release token。
- 不登录你的平台。
- 不替你发布真实版本。
- 不处理 KYC、付款、生产系统变更。
- 不承诺 PR 合并、赏金或平台通过。

## 需要材料

- 仓库链接。
- issue / PR / 失败日志链接。
- 期望结果。
- 能接受的改动范围。
- 必须保留的发布规则。

GitHub PR

PR 描述

改前

This PR delivers a production-grade fix with comprehensive validation and seamless integration for the whole repository.

改后

The failure is in `on_event()`: blank event names are accepted and written into handler metadata. This patch rejects non-string, empty, and whitespace-only names before metadata is created.

删掉“production-grade”，改成具体失败点、改动位置和边界。

漏洞报告

安全影响

改前

This critical vulnerability can fully compromise the platform and cause severe business damage.

改后

A webhook URL can point to loopback or private hosts. If the server sends the request from its own network, this may expose internal-only endpoints. I did not test against production systems.

把夸张影响改成攻击条件、可能影响和未做事项。
